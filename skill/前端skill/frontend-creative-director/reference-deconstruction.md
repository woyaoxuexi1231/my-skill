# Reference Deconstruction

Use when the user provides reference URLs or screenshots.

## Rules

- Do **NOT** reproduce or clone the reference
- Do **NOT** copy exact layout, typography, content, colors, imagery, or animations
- Study **underlying creative principles**
- Analyze as a senior Creative Director / Digital Art Director

## Analyze these dimensions

### 1. Creative Concept
Central idea. Why it feels like a brand experience, not a conventional site.

### 2. Visual Identity
Color, typography, scale, contrast, whitespace, density, imagery, texture, repetition.

### 3. Composition
Grid, alignment, asymmetry, oversized elements, negative space, overlap, full-bleed, unconventional positioning.

### 4. Typography as Visual Material
Oversized/repeated/broken/vertical text; text as shape; extreme scale; unusual spacing.

### 5. Motion
Scroll, reveals, transitions, image/type movement, pacing — the overall motion **language**, not a list of effects.

### 6. Interaction
Nav, hover, scroll, sound, cursor, unexpected exploration cues.

### 7. Image / Object Language
Object selection, metaphors, placement, cropping, scale, relation to type.

### 8. Information Architecture
Narrative sequence — not “standard landing page sections.”

### 9. Anti-Generic Principles
What prevents SaaS / template / AI-slop feeling.

### 10. Transferable Design Principles
10–15 reusable principles.

Bad: “Use the same giant text.”  
Good: “Use typography as a spatial object rather than merely as information.”

Bad: “Use the same B/W palette.”  
Good: “Use a restrained palette so composition and typography carry identity.”

## Final output format

1. Reference Creative Concept  
2. Visual Language  
3. Composition Principles  
4. Typography Principles  
5. Motion Principles  
6. Interaction Principles  
7. Image Principles  
8. Narrative Structure  
9. Anti-AI-Slop Principles  
10. Transferable Design Principles  

Then:

## What We Should Borrow
Principles only.

## What We Should NOT Borrow
Specific decisions that would make the new project a clone.

**Research only unless user explicitly asks to implement.**
