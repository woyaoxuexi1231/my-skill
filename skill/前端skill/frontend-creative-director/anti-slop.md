# Anti-AI-Slop Checklist

Hard bans for premium editorial / fashion / culture / portfolio work.

If any item appears, remove it before shipping.

## Visual bans

- Purple-to-blue / purple-to-indigo gradients as “premium”
- Glassmorphism, neon glow, aurora blobs, floating gradient orbs
- Particle fields, mesh gradients as hero identity
- Pure digital harsh black/white when a warm gallery grade fits better
- Multi-layer soft UI shadows everywhere
- Rounded-full pill clusters as decoration
- Emoji as design system

## Layout bans

- Card grids / equal tiles / “portfolio masonry of sameness”
- Cards inside cards
- Standard SaaS IA as default: Hero → Features → Pricing → FAQ → Testimonials
- Dashboard-looking first viewport on a brand/portfolio page
- Inset hero media cards / floating media tiles when full-bleed or intentional crop is the concept
- Detached promo stickers / floating badges on hero media

## Type bans

- Inter / Roboto / Arial / system-ui as the brand voice
- Giant glowing gradient text
- Everything the same size (no extreme scale contrast)
- Treating display type only as a polite heading

## Motion / interaction bans

- Bounce / elastic overshoot as personality
- Animating every element on load
- Grayscale → color image hover gimmicks
- Magnetic cursor / custom “tech” cursors by default
- Parallax circus (keep subtle or none)

## Content bans

- “Hello, I’m X 👋” startup intro energy on luxury/editorial briefs
- Salesy feature bullets where a gallery statement belongs
- Invented stock faces / fake portraits when assets are missing

## Positive replacements

| Instead of | Prefer |
| ---------- | ------ |
| Card grid | Staggered image chapters, full-bleed, offset crops |
| Soft UI shadow stack | Overlap, crop, paper warmth, film grade |
| Inter | Distinct display serif/sans pairing with intent |
| Feature row | One focal point + breathing void |
| Loud CTA button | Quiet text CTA / editorial link |

## Final instruction

Do not build a standard website costume.

Build a **visual experience** that feels closer to a printed art book or private gallery than to a template.
