# Visual Critique Lenses (detail)

## Cheap vs expensive signals

| Cheap | Expensive |
| ----- | --------- |
| Equal card tiles | Staggered chapters / bleeds |
| Centered safe hero | Intentional crop / asymmetry |
| Inter + purple glow | Chosen type pair + restrained palette |
| Everything animated | Sequenced reveals |
| Loud buttons | Quiet editorial CTAs |
| Busy first viewport | One focal point + void |

## Common failure modes (from real builds)

1. **Wrong cut** — dramatic crop caused by overlapping panel, not by frame edge  
2. **Sidebar reading** — media becomes a full-height column instead of a fragment  
3. **Subtitle infection** — metadata sits on title axis like marketing subcopy  
4. **Missing word space / broken display type** — brand name collapses  
5. **Wireframe placeholders dominating** — construction labels too loud  
6. **Mixed asset worlds** — anime + stock city + luxury CD claim = taste crash  
7. **Concept-correct CSS, concept-invisible screen** — specs not readable in pixels  

## Fix Pass quality bar

Good fix instruction:

> Strengthen left overshoot until ~25–30% of the name is outside the viewport. The cut must come from the hero edge, not from the portrait block.

Bad fix instruction:

> Make the hero nicer and more premium.
