# React Bits Guide

React Bits ([reactbits.dev](https://reactbits.dev) / [GitHub](https://github.com/DavidHDev/react-bits)) is a **menu of effects**, not a design system.

## When to use

- Brief asks for memorable motion
- Hero/background/text needs a specific effect family
- `find-animation-opportunities` / `improve-animations` identified a justified slot

## When NOT to use

- Editorial/luxury briefs that need restraint (prefer CSS transform/opacity)
- As a substitute for art direction
- Sprinkling effects on every section

## How to integrate

1. Pick **1–3** components max for a marketing/portfolio page unless brief is experimental
2. Prefer copy-paste / shadcn-style add of a single component over wholesale dependency sprawl
3. Restyle to project tokens (colors, easing, typography)
4. Always add `prefers-reduced-motion` fallbacks
5. After adding, run `review-animations` standards mentally

## Companion skills in this pack

- `find-animation-opportunities`
- `improve-animations`
- `review-animations`
- `apple-design` (only when Apple-like restraint is the brief)
